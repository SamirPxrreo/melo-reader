## ⚡ Descarga e Instalación Rápida

### 📥 [Descargar MeloReader-Setup.exe](https://github.com/SamirPxrreo/melo-reader/releases/latest)

1. Descarga el instalador **`MeloReader-Setup.exe`**.
2. Dale doble clic y sigue el asistente paso a paso (*Siguiente, Siguiente, Instalar, Finalizar*).
3. ¡Listo! Crea accesos directos en el **Escritorio**, en el **Menú Inicio** y asocia tus archivos `.md` para abrirlos automáticamente con Melo Reader.

## ✨ Características "Todo Melo"

### 🎨 7 Paletas de Colores Vibrantes & Estéticas
- **Cyberpunk Neón:** Violeta medianoche con acentos cian y magenta eléctrico.
- **Tokyo Matcha:** Tonos esmeralda y verde bosque relajantes.
- **Catppuccin Mocha:** Tonos pastel modernos de alto confort visual.
- **Papel Editorial Tibio:** Textura cálida tipo libro impreso.
- **Synthwave Sunset:** Gradientes ochenteros magenta y oro.
- **Obsidian OLED Dark:** Negro puro con contraste monocromático fino.
- **Glacier Ártico:** Azules nórdicos limpios y frescos.

### 🔤 Tipografía Premium Seleccionada
- **Lectura:** *Outfit*, *Plus Jakarta Sans*, *Inter*, *Syne*, *Space Grotesk*, *Playfair Display*, *Cinzel*, *Lora*.
- **Código:** *JetBrains Mono* y *Fira Code* con soporte completo para ligaduras.
- **Controles en vivo:** Sliders de tamaño de fuente, interlineado (line-height) y ancho de lectura (max-width).

### 🏛️ Barra de Comandos Rediseñada (Impeccable & Anti-UI-Slop)
- **Zona Izquierda:** Logo oficial y cápsula de documento con tiempo estimado de lectura en tiempo real.
- **Zona Central:** Barra de búsqueda rápida integrada estilo Linear/Raycast (`Ctrl + K`) y botón de Índice (TOC) con contador dinámico de secciones.
- **Zona Derecha:** 
  - 🎧 **Lector de Voz (TTS):** Escucha tus apuntes con indicador animado de pulso.
  - 🎨 **Selector de Temas:** Con previsualización activa del color del tema.
  - 🔲 **Modo Zen:** Lectura inmersiva a pantalla completa sin distracciones.
  - 🖨️ **Exportación a PDF / Impresión:** Formato editorial optimizado.
  - 📂 **Botón de Abrir Archivo:** Con atajo de teclado nativo.

### 📐 Renderizado Avanzado de Markdown
- **Fórmulas Matemáticas KaTeX:** Renderiza `$E = mc^2$` y bloques de fórmulas complejas `$$...$$`.
- **Diagramas Mermaid:** Diagramas de flujo y arquitectura generados en vivo.
- **Bloques de Código:** Con detección de lenguaje y botón de copiado en 1 clic.
- **Callouts / Avisos Especiales:** `[!NOTE]`, `[!TIP]`, `[!WARNING]`, `[!CAUTION]`.
- **Listas de Tareas Interactivas:** Checkboxes clicables con feedback visual.

## ⌨️ Atajos de Teclado

| Atajo | Acción |
| :--- | :--- |
| <kbd>Ctrl + K</kbd> o <kbd>Ctrl + F</kbd> | Abrir buscador rápido dentro del documento |
| <kbd>Ctrl + O</kbd> | Abrir archivo Markdown (.md) desde el explorador |
| <kbd>Alt + T</kbd> | Abrir / Cerrar la Tabla de Contenidos (Índice) |
| <kbd>Alt + Z</kbd> | Activar / Desactivar el Modo Zen |
| <kbd>Ctrl + P</kbd> | Imprimir o Exportar a PDF |
| <kbd>Esc</kbd> | Cerrar modales o salir del Modo Zen |

## 🛠️ Ejecución desde el Código Fuente

Si deseas correr o modificar el código fuente:

```bash
# Clonar el repositorio
git clone https://github.com/SamirPxrreo/melo-reader.git
cd melo-reader

# Instalar dependencias
npm install

# Iniciar la app de escritorio
npm start

# O iniciar como servidor web ligero
npm run serve
```
